## Why Notes

- Your notes stay on your phone.
- Each note is a simple file in a folder you choose.
- Read, write or edit the text in one place.
- Clean and easy to use.

## Write

<img align="right" width="220" alt="Writing tools" src="docs/screenshots/edit.png" />

- Read a note, write with formatting, or edit the raw text.
- Add headings, lists, tasks, quotes and code.
- Add callouts, highlights and footnotes.
- Create tasks with your own states.
- Find and replace text in a note.
- Undo, redo and autosave.

<br clear="right" />

## Tables

<img align="right" width="220" alt="Insert a table" src="docs/screenshots/insert-table.png" />

- Drag to choose the table size.
- Edit cells right in the table.
- Add, move, copy or delete rows and columns.
- Align each column.

<br clear="right" />

## Properties

<img align="right" width="220" alt="Note properties" src="docs/screenshots/properties.png" />

- Add tags, dates, lists, numbers and checkboxes to a note.
- Group tags like `work/projects`.
- Show or hide the panel.

<br clear="right" />

## Link your ideas

<img align="right" width="220" alt="Unlinked mentions" src="docs/screenshots/mentions.png" />

- Link notes with `[[double brackets]]`.
- Link to a heading or a paragraph.
- Show other notes inside a note.
- See which notes link to this one.
- Get suggestions for mentions without a link.
- Links update when you rename a note.

<br clear="right" />

## Outline

<img align="right" width="220" alt="Outline" src="docs/screenshots/outline.png" />

- See all headings of a note.
- Tap a heading to jump to it.
- See the notes it links to.

<br clear="right" />

## Connections

<img align="right" width="220" alt="Connections map" src="docs/screenshots/connections.png" />

- See your notes as a map.
- Start from a folder, note, tag or file.
- Tap a note to move through the map.
- Tap the center to see what is related.

<br clear="right" />

## Pending

<img align="right" width="220" alt="Pending" src="docs/screenshots/pending.png" />

- Find notes with no links.
- Find broken links.
- Create a missing note in one tap.

<br clear="right" />

## Search

<img align="right" width="220" alt="Search" src="docs/screenshots/search.png" />

- Search by title or content.
- Filter by tag, folder, pinned or images.
- Save the searches you use often.
- See your recent searches.

<br clear="right" />

## Organize

<img align="right" width="220" alt="Folders" src="docs/screenshots/drawer.png" />

- Browse one folder at a time.
- Press and hold a folder to see its actions.
- Sort by name or date.
- Pin your favorite notes.
- Duplicate a note or move it to another folder.
- Use several folders, each with subfolders.

<br clear="right" />

## Tags

<img align="right" width="220" alt="Tags" src="docs/screenshots/tags.png" />

- Browse your notes by tag.
- Nested tags are grouped for you.

<br clear="right" />

## Templates

<img align="right" width="220" alt="Templates" src="docs/screenshots/templates.png" />

- Start a note from a template.
- Create your own templates.
- Fill in the date, time or title automatically.
- Open today's note in one tap.
- Choose the folder for new notes.

<br clear="right" />

## Version history

<img align="right" width="220" alt="Version history" src="docs/screenshots/history.png" />

- Go back to an earlier version of a note.
- Compare changes before you restore.

<br clear="right" />

## Share and export

<img align="right" width="220" alt="Export" src="docs/screenshots/export.png" />

- Export or share as Markdown, HTML or PDF.
- Import the notes you already have.
- Open text files from other apps.
- Add images, audio, video and PDFs.
- Take a photo and add it to a note.

<br clear="right" />

## Make it yours

<img align="right" width="220" alt="Settings" src="docs/screenshots/settings.png" />

- Choose light, dark or your phone's theme.
- Pick an accent color.
- Pick a font for titles.
- Change the text size and width.
- Turn line numbers and spellcheck on or off.
- Use it in 15 languages.

## Contribute

1. Fork the repository and clone it.
2. Install with `npm install`.
3. Connect your Android phone with a USB cable.
4. Run `npx expo start`.
5. Make your changes and open a pull request.
