# Welcome

This is your first note. A quick tour of what's new, section by section.

## ✨ Style and structure your text
* **Bold**: add ** around the word to make it stand out more.
* *Italic*: add * around the word for a softer emphasis.
* ~~Strikethrough~~: add ~~ around the word to mark it as discarded.
* `Code`: add ` around the word to show it in code format.
* **Quote**: add > at the start of the line to highlight an important part.

> This is what a highlighted quote looks like.

* **To-do list**: add - [ ] at the start of the line to mark something pending.

- [ ] Check this off once you're done

* **Table**: add | between each column to sort data into rows and columns.

## 📎 Attach files
* **Preview**: write `![[photo.png]]` to show a supported file right inside the note.
* **Other files**: write `[[document.pdf]]` to get a chip that opens it in another app.

Find every attached file in the **Files** view of the side menu.

---

## 🧰 More tools
* **Tags**: Organize your notes by topic and find them fast.
* **Templates**: Create new notes with a ready-to-use structure.
* **Version history**: Go back to an earlier version of your note.
* **Export**: Save your note as a Markdown file.
* **Share**: Send it straight to another app.
* **Daily note**: Tap the calendar button in the drawer to open today's note. Pick its folder and template in Settings.
